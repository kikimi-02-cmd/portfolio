# 業務自動化LP — Google広告 入稿・計測・判定 設計書

対象ページ: `/automation`（実装: `src/app/automation/`）
月予算: **¥30,000**（日予算 ¥1,000）
目的: **「この提供内容に金を払う個人事業主が存在するか」を2週間で確定させる**

---

## §1 なぜ検索広告なのか（SNS広告ではなく）

| | 検索広告 | SNS広告 |
|---|---|---|
| 当たる相手 | **いま探している人** | まだ探していない人 |
| 必要な前提 | なし | 認知・興味の育成 |
| 少額での有効性 | 高い（意図が濃いのでCV率が高い） | 低い（母数が要る） |

フォロワー数がゼロに近い状態で認知型の広告を打つのは、7ヶ月ゼロだった経路の再演になる。
**発注意図のある検索語だけを刈る。**

## §2 キャンペーン設定（ここを間違えると予算が溶ける）

| 設定項目 | 値 | 理由 |
|---|---|---|
| キャンペーンタイプ | 検索 | |
| **「ディスプレイ ネットワークに拡張」** | **オフ** | 既定でオンになっている。放置すると予算の大半が無関係な面に流れる |
| **「検索パートナー」** | **オフ** | 品質が読めない。少額テストではノイズ |
| 地域 | 日本 | |
| 地域オプション | **「所在地」のみ**（「興味を示した地域」を外す） | 既定は興味も含む。海外からの流入を排除 |
| 言語 | 日本語 | |
| 入札 | **手動CPC（上限 ¥250）** | コンバージョン実績0で自動入札を選ぶと学習できず暴走する。**CVが10件貯まるまで手動** |
| 広告のローテーション | 均等に配信 | テストのため |
| 日予算 | ¥1,000 | |
| 広告スケジュール | 終日 | 初回は絞らない（時間帯データを取るため） |

## §3 広告グループとキーワード

### グループA（本命・予算50%）— スプレッドシート/GAS

発注意図が明確で、法人向けSaaSが入札していないためCPCが安い。確実に納品できる領域。

```
[GAS 開発 依頼]
[Google Apps Script 外注]
"GAS 代行"
"スプレッドシート 自動化 依頼"
"スプレッドシート 自動化 外注"
"Googleスプレッドシート 自動化 依頼"
```

### グループB（予算25%）— Notion

```
[Notion 構築 代行]
"Notion 導入 依頼"
"Notion 構築 外注"
"Notion 業務 効率化 依頼"
```

### グループC（予算25%）— Excel / CSV

```
"Excel 自動化 外注"
"エクセル 集計 自動化 依頼"
"CSV 集計 自動化 依頼"
"エクセル マクロ 作成 依頼"
```

### グループD（当面停止）— 新語

CPCは安いが母数が読めない。A〜Cの結果を見てから開放する。

```
"Claude Code 代行"
"AI ツール 作成 依頼"
"業務自動化 個人事業主"
```

記号の意味: `[完全一致]` / `"フレーズ一致"`。**部分一致は使わない**（少額では発散する）。

## §6 計測の設置（広告を出す前に必ず終わらせる）

**計測が入っていない広告は、金を捨てるのと同じ。** 順番を守ること。

1. **フォーム送信先を設定する**
   - Formspree（無料枠あり）でフォームを作成し、エンドポイントを取得
   - `src/app/automation/page.tsx` の `FORM_ENDPOINT` を差し替え
   - `THANKS_URL` を本番ドメインの `https://<本番ドメイン>/automation/thanks` に差し替え
2. **Google広告のコンバージョンアクションを作成**
   - 種類: ウェブサイト / カテゴリ: 見込み顧客のフォーム送信
   - 値: **¥50,000**（診断1件の売上。ROASが読めるようになる）
   - カウント方法: **1回**（同一ユーザーの重複送信を数えない）
3. **Google タグ（gtag.js）をサイトに設置**
   - `src/app/layout.tsx` に gtag スニペットを追加
   - `src/app/automation/thanks/page.tsx` の `CONVERSION_SEND_TO` を実IDに差し替え
4. **テスト送信**
   - 自分でフォームを送信し、`/automation/thanks` に着地することを確認
   - Google広告の管理画面で、24時間以内にコンバージョンが1件計上されることを確認
   - **ここが確認できるまで広告を配信しない**

## §7 予算配分と進め方

| 期間 | 使う予算 | やること |
|---|---|---|
| 前半2週 | ¥15,000 | グループA・B・C を同時配信。検索語句レポートを**2日に1回**見て除外を追加 |
| 後半2週 | ¥15,000 | クリック単価とCV率が最も良かったグループに全額寄せる |

**検索語句レポートの確認だけは絶対に飛ばさない。** 実際に何と検索された人が来ているかを見て、
無関係な語をその都度除外に追加する。これが少額運用で唯一効く作業。

## §8 想定値と判定基準

### 想定

| 指標 | 目標 |
|---|---|
| CPC | ¥100〜250 |
| クリック数（¥30,000） | 150〜300 |
| LPのCV率 | 2〜4% |
| 問い合わせ数 | 3〜12件 |
| CPA | ¥5,000〜15,000 |

診断（¥50,000）が1件でも成約すれば、CPA ¥15,000 でも回収できる。

### 判定（¥30,000 消化時点）

| 結果 | 解釈 | 次の一手 |
|---|---|---|
| **問い合わせ 0件** | オファーかキーワードが外れている。LPの文言の問題ではない | **オファーから組み直す**。LPの微調整に時間を使わない |
| **1〜2件** | 市場は存在する。効率が悪いだけ | 勝ちキーワードに寄せて翌月継続 |
| **3件以上** | 需要あり | 予算増額を検討。同時受注1件の制約とぶつかるので、先に価格を上げる |

### 先に認めておく限界

¥30,000・クリック150〜300は**統計的には弱い**。CV率の精度は出ない。
このテストで分かるのは「**ゼロか、ゼロでないか**」だけ。

ただし、これまで7ヶ月で得られた情報量はゼロだった。
**2週間で「ゼロか否か」が確定するなら、情報の増分は無限大**である。ここを取り違えない。

## §9 やってはいけないこと

- CV実績0のまま**自動入札（コンバージョン数の最大化）に切り替える** — 学習データがなく暴走する
- **部分一致キーワードを足す** — 少額では発散する
- 問い合わせ0件のときに**LPの色やボタン文言を触る** — 原因はほぼオファー側にある
- **配信を1週間放置する** — 検索語句レポートを見ない運用は、除外が育たず単価が上がり続ける
- 成果が出る前に**予算を増やす**
